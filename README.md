# ML10_RNN_Name_Generation_and_Gender_Classification
Реализация рекуррентных нейронных сетей на PyTorch для генерации имён и определения пола по имени. Сравнение RNN, GRU и LSTM, анализ перплексии, исследование проблемы исчезающего градиента, многозадачное обучение и визуализация символьных эмбеддингов с помощью PCA и t-SNE.
