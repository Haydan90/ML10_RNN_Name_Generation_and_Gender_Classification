# ML10 — Генерация имён и классификация пола с помощью RNN

В этом проекте я изучал применение рекуррентных нейронных сетей (RNN) для работы с последовательностями символов.

Основная цель — реализовать и сравнить три архитектуры: обычную RNN, GRU и LSTM. На их основе я решил две задачи: генерацию новых имён и бинарную классификацию пола по имени.

Дополнительно я исследовал проблему исчезающего градиента, сравнил языковые модели по перплексии, реализовал многозадачное обучение и визуализировал эмбеддинги символов.

## Датасет

Для проекта использовался файл `babynames-clean.csv` ссылка на датасет: https://data.world/alexandra/baby-names?utm_source=chatgpt.com,  содержащий имена и соответствующие метки пола.

В таблице используются два столбца:
- `Name` — имя;
- `Gender` — пол, обозначенный значениями `boy` и `girl`.

В датасете содержится 6782 записи:
- 3437 имён с меткой `boy`;
- 3345 имён с меткой `girl`.

Данные разделены на три выборки с сохранением пропорций классов:
- обучающая — 5425 записей;
- валидационная — 678 записей;
- тестовая — 679 записей.

Для разделения использовался `train_test_split` с `random_state=21` и стратификацией по полу.

Исходный файл должен находиться в папке `data`. Ссылка на источник датасета в ноутбуке не указана.

## Что было сделано

### 1. Разведочный анализ данных

- Загрузил данные с именами и метками пола.
- Изучил распределение имён по классам.
- Построил распределение длин имён.
- Проанализировал частоты встречаемости букв.
- Подготовил данные для работы с последовательностями символов.

Распределение классов относительно сбалансировано: количество имён с метками `boy` и `girl` примерно одинаковое.

### 2. Подготовка последовательностей

Реализовал символьное кодирование имён для последующей обработки нейронной сетью.

В словарь включены 26 букв английского алфавита и три специальных токена:
- `<SOS>` — начало последовательности;
- `<EOS>` — конец последовательности;
- `<PAD>` — заполнение последовательности до фиксированной длины.

Каждое имя преобразуется в последовательность числовых индексов. Для классификации пола также создаётся бинарная метка: `girl` — 1, `boy` — 0.

Для представления символов используется обучаемый слой `Embedding`.

Основные параметры моделей:
- размерность эмбеддинга — 128;
- размер скрытого состояния — 256;
- размер батча — 64;
- начальная скорость обучения — 0.001;
- оптимизатор — Adam.

### 3. Генерация имён с помощью RNN

Реализовал собственную рекуррентную нейронную сеть для предсказания следующего символа последовательности.

Модель получает имя посимвольно и обучается предсказывать следующий токен. Для обучения используется `CrossEntropyLoss`.

После обучения реализовал генерацию имён:
- генерация начинается с токена `<SOS>`;
- на каждом шаге модель предсказывает распределение вероятностей следующего символа;
- следующий символ выбирается случайно с учётом этого распределения;
- генерация заканчивается при появлении `<EOS>` или достижении максимальной длины.

Для управления разнообразием генерируемых имён используется temperature sampling.

### 4. Сравнение RNN, GRU и LSTM

Реализовал три варианта рекуррентной архитектуры:
- **RNN** — базовая рекуррентная сеть с обновлением скрытого состояния;
- **GRU** — сеть с механизмами ворот, регулирующими обновление состояния;
- **LSTM** — сеть с отдельным состоянием памяти и механизмами управления информацией.

Для каждой архитектуры обучил отдельную языковую модель и построил графики изменения функции потерь на обучающей и валидационной выборках.

Для остановки обучения использовался Early Stopping.

### 5. Оценка языковых моделей

Для сравнения моделей использовал перплексию — метрику, характеризующую способность языковой модели предсказывать последовательность символов.

Также рассчитал перплексию двух простых базовых вариантов:
- равномерной модели;
- модели, использующей частоты встречаемости токенов.

Результаты на валидационной выборке:

| Модель | Perplexity |
|---|---:|
| RNN | 3.19 |
| GRU | 3.17 |
| LSTM | 3.13 |

Наименьшую перплексию показала LSTM. В рамках проведённого эксперимента она лучше остальных моделей предсказывала следующие символы имён.

### 6. Классификация пола по имени

Использовал те же архитектуры RNN, GRU и LSTM для решения задачи бинарной классификации.

В модель добавлена отдельная выходная голова, предсказывающая вероятность принадлежности имени к классу `girl`.

Для обучения использовались:
- функция потерь `BCEWithLogitsLoss`;
- оптимизатор Adam;
- оценка на валидационной выборке;
- Early Stopping.

Качество классификации оценивалось с помощью ROC-AUC на тестовой выборке.

| Модель | Test ROC-AUC |
|---|---:|
| RNN | 0.8961 |
| GRU | 0.9046 |
| LSTM | 0.9127 |

Лучший результат среди отдельных моделей показала LSTM с ROC-AUC 0.9127.

Это указывает на то, что LSTM в данном эксперименте лучше разделяла имена двух классов.

### 7. Исследование исчезающего градиента

Провёл эксперимент для изучения проблемы исчезающего градиента в рекуррентных нейронных сетях.

Рассмотрел два сценария:
- языковая модель, в которой функция потерь рассчитывается по предсказаниям следующих символов;
- классификация пола, в которой ошибка рассчитывается по итоговому скрытому состоянию.

Реализовал сбор градиентов слоя эмбеддингов с помощью backward hook и построил графики норм градиентов по позициям символов.

Эксперимент позволил сравнить распространение градиента через последовательность для RNN, GRU и LSTM и продемонстрировать, почему обычные RNN испытывают трудности при обучении на длинных зависимостях.

### 8. Многозадачное обучение

Реализовал многозадачную LSTM, которая одновременно решает две задачи:
- генерация следующего символа имени;
- классификация пола по имени.

Модель использует общее представление последовательности и две выходные головы. Итоговая функция потерь складывается из потерь языковой модели и классификатора.

Для классификации используется `BCEWithLogitsLoss`, для предсказания символов — `CrossEntropyLoss`.

Результат на тестовой выборке:

| Модель | Test ROC-AUC |
|---|---:|
| LSTM | 0.9127 |
| LSTM с многозадачным обучением | 0.9272 |

Многозадачная модель показала лучший ROC-AUC среди проверенных вариантов классификации пола.

В рамках данного эксперимента совместное обучение двух задач улучшило качество классификации по сравнению с отдельной LSTM.

### 9. Визуализация эмбеддингов

Исследовал обученные представления символов с помощью методов снижения размерности:
- PCA;
- t-SNE.

Преобразовал эмбеддинги LSTM в двумерное пространство и визуализировал расположение символов.

На графиках отдельно выделены гласные, что позволяет исследовать структуру обученных представлений и возможные закономерности в расположении букв.

### 10. Сохранение и загрузка модели

Сохранил обученную многозадачную LSTM в файл `data/multitask_model.pkl`.

В checkpoint записываются:
- веса модели;
- размер словаря;
- размерность эмбеддингов;
- размер скрытого состояния;
- тип архитектуры.

После сохранения восстановил модель, загрузил веса и повторно оценил качество на тестовой выборке.

ROC-AUC после загрузки составила 0.9272, что совпало с результатом до сохранения.

Также сохранил предсказанные вероятности для тестовой выборки в `data/test_predictions.csv`.
